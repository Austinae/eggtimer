# EggTimer <img src="https://github.com/user-attachments/assets/06161a8e-5dd1-4bfc-96da-515f5db51d6e" align="right" width="120" />

Floating hyper-minimalist macOS egg timer. Hover for controls. Always on top.

## Controls

Start · Pause/Continue · Restart · Stop · Close (hover top-right)

Durations: 15m · 30m · 1h

## Download

On App Store soon.

## Requirements

Most modern Macs (Both Intel and Apple Silicon)

## Run from source

```bash
swift run
```
